# Cytology — Thai Cell Biology Learning Site

Minimal, responsive educational website inspired by the structure and learning topics in `56802-cmd/cytology`.

## Run locally
Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production
```bash
npm run build
npm start
```

## Included
- Thai-language cell biology learning page
- Nine selectable lesson topics
- Responsive navigation and lesson cards
- Interactive multiple-choice quiz with explanations and score
- Searchable glossary
- Mobile-friendly layout

## Notes
This is a standalone implementation based on the visible page structure and topics of the linked repository, not a direct commit to the GitHub repository. Review the lesson text for scientific accuracy and expand it with the original components/assets before using it as formal instructional material.
